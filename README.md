## List of Programs

### 1. Function Overloading
Demonstrates compile-time polymorphism by defining multiple `add()` functions with different parameter lists.

### 2. Area Calculator Using Function Overloading
Calculates the area of a square, rectangle, circle, and triangle using overloaded functions.

### 3. Unary Minus Operator Overloading
Demonstrates overloading of the unary `-` operator for a user-defined `Number` class.

### 4. Prefix and Postfix Increment/Decrement Operator Overloading
Demonstrates prefix and postfix `++` and `--` operators using a `Counter` class.

### 5. Binary + and - Operator Overloading for Complex Numbers
Demonstrates binary operator overloading to perform addition and subtraction of complex numbers.

### 6. Relational Operator Overloading
Demonstrates overloading of relational operators `>` and `==` for comparing `Distance` objects.

### 7. Friend/Non-Member Operator Overloading
Demonstrates friend functions for operator overloading, including expressions such as `10 + complexNumber` and `10 - complexNumber`.

### 8. Base Pointer Without a Virtual Function
Demonstrates static binding when a base-class pointer calls a non-virtual function.

### 9. Base Pointer With a Virtual Function
Demonstrates run-time polymorphism using a base pointer and virtual functions.

### 10. Base Reference With a Virtual Function
Demonstrates run-time polymorphism using a base-class reference with different derived shape objects.

### 11. Abstract Class and Pure Virtual Function
Demonstrates an abstract class containing a pure virtual function and its implementation in derived classes.

### 12. Collection of Polymorphic Shape Pointers
Demonstrates storing different derived shape objects using `vector` and `unique_ptr` with a common base-class interface.

### 13. Virtual Destructor
Demonstrates the importance of a virtual destructor when deleting a derived object through a base-class pointer.

### 14. Object Slicing Demonstration
Demonstrates object slicing when a derived object is passed by value as a base-class object and compares it with reference and pointer passing.

### 15. Payment Processing System
Demonstrates run-time polymorphism using an abstract `Payment` class with Card, UPI, Net Banking, and Wallet payment methods.

### 16. Employee Payroll Mini-Project
Demonstrates abstract classes and run-time polymorphism by calculating salaries for permanent, contract, and freelance employees and displaying the total payroll.
